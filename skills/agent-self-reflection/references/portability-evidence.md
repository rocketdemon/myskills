# 移植证据：判据只依赖 9 个字段

这份文件记录「可移植」是怎么被证明的，而不是怎么被相信的。试验脚本与夹具**不随包发布**（含本机绝对路径），只发布结论与数字。

## 一、静态证据：19 处取数点，列依赖全在契约内

`daily-reflection.py`（1,912 行）里含 `FROM`/`JOIN` 的 SQL 片段共 19 处，只碰 3 张表：

| 表 | 被引用的列 | 是否在契约内 |
|:--|:--|:--|
| `messages` | `id` / `session_id` / `role` / `content` / `timestamp` | ✅ 全部 |
| `sessions` | `id` / `title` / `started_at` / `source` | ✅ 全部 |
| `delivery_obligations` | `state` / `content` / `created_at` / `last_error` | ❌ 平台专有，整段删除 |

**关键反证**：`sessions` 表实际还有 `user_id` 等列，脚本**从不读取**。
把最小 schema 库灌数据时才发现这点（插入报 `table sessions has no column named user_id`）——
即「最小契约够用」是被一次真实的报错逼出来的结论，不是推断。

**分析器自身的假阳性**（记录下来，提醒后来者）：第一版把一条 SQL 里 `sessions` 主查询与
`messages` 子查询的列合并成一个集合再按表比对，报出 4 处「契约外列」，逐行核对**全部是假阳性**
（例如把 `messages` 子查询里的 `timestamp` 算到 `sessions` 头上）。判据坏掉时，输出与「真有问题」同形。

## 二、动态证据：同一份脚本，两种库结构，输出逐行比对

做法：把脚本正文一字不改，只把 `STATE_DB` / `SINCE_TS` 改成读环境变量，然后喂两个库：

- A 组：原生 `state.db`（完整 schema）
- B 组：`portable.db`（只含契约字段）

| 轮次 | 窗口 | 数据量 | 结论 |
|:--|:--|:--|:--|
| 1 | 10-13 起 | 9 会话 / 4,363 消息 | 112 行 vs 113 行，差异 3 处（运行时刻、在线占比、窗口内消息数）——全部环境性 |
| 2 | 10-11 起 | 18 会话（含 6 subagent）/ 7,209 消息 | 138 行 vs 138 行，差异 3 处，同上；守卫留痕逐字相同 |
| 3 | 08-14 起 | 113 会话 / 25,782 消息 | 189 行 vs 189 行；**暴露 `SESSION_SCAN_LIMIT=20` 截断**（113 个会话只有 20 个被扫） |

差异**全部**是这三类，没有一条属于判据差异：脚本运行时刻、journal 在线占比（活数据在增长）、
窗口内消息数（试验期间会话仍在写入）。

## 三、命中分支：把「0 信号」变成「真跑过」

前两轮的核心段（纠正 / 手动介入 / 重复失败）命中数都是 0 —— **两侧都是 0 证明不了可移植**，
因为那只是「无信号路径一致」。补法：

1. 把窗口收窄成 1 天（08-15），避开 20 会话上限；
2. 在 A、B 两个库里**注入同一批合成样本**（假 schema 差异成为唯一变量）；
3. 结果两侧都是 `2 纠正 + 1 手动介入`，且时间戳、severity 逐字相同
   （其中「还是不好」来自真实语料，「不对」「我手动」来自注入样本）。

## 四、可移植版的等价性验证

可移植版 `reflect.py` 不是重写，而是**逐字搬段落**（`build-explore.py` 按行号切片）：
保留通用工具函数、会话选取、SECTION 1/1b/1c/1d/2/3/4、覆盖率自检、窗口连续性；删除环境专属五段。

同一份数据，两条路径对比：

| 判据 | 原全脚本（走库） | reflect.py（走 JSONL） |
|:--|:--|:--|
| 核验追问 | 13 | 13 |
| 术语/抱怨追问 | 7 | 7 |
| harness 排除 | 4 | 4 |
| 跨话题过滤 | 2 | 2 |
| 虚假声称 | 2 | 2 |
| 纠正 / 手动介入（注入窗口） | 2 / 1 | 2 / 1 |

## 五、仍未验证（别当已证）

- `title` / `role` 值域 / `ts` 格式的适配层：契约里直接用了原生形状，**换 agent 时这层没测过**
- 英文会话：不覆盖（词表是中文长出来的）
- 四个环境专属段在原试验里「输出也一致」是**假象**——它们读的是活系统，不是契约
